# Phonology Battle

A modern single-page website for the Phonology Battle project.

## Features
- Landing page with interactive challenge card
- Responsive design for desktop and mobile
- Lightweight HTML, CSS, and JavaScript

## Run locally
Open `index.html` in a browser, or serve the folder with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
